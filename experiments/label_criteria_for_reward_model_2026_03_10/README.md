# Labeling criteria for our reward model

See [this Github issue](https://github.com/METResearchGroup/mirrorview/issues/28). In `experiments/train_prompt_optimization_2026_03_10`, we transform our preference data into a form that shows which flips were preferred. Now we label the model based on our 6 criteria in order to make sure that flips meet each of the 6 criteria for a "valid flip".
